# Sampon ansioluettelo

Staattinen ansioluettelo, joka on toteutettu HTML:llä ja CSS:llä.

## Julkaisu GitHub Pages -sivuna

1. Avaa repositorion **Settings → Pages**.
2. Valitse kohdasta **Build and deployment** lähteeksi **Deploy from a branch**.
3. Valitse `main`-haara ja kansio `/ (root)`, tallenna asetukset.
4. Sivusto löytyy hetken kuluttua osoitteesta `https://sampoaatos.github.io/CS-ei-oikee-/`.

Sähköpostiosoite on tällä hetkellä esimerkkiosoite `sampo@example.com`. Vaihda se `index.html`-tiedostossa omaan osoitteeseesi ennen julkaisua.
